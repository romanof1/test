# Обществоведение: тренажёр и поиск по учебнику

Статический сайт для учащихся 9–10 классов (подготовка к олимпиаде). Сборка не нужна.

## Как открыть
- **Локально:** откройте `docs/index.html` в браузере.
- **Для учеников (GitHub Pages):** Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/docs`.
  Сайт появится по адресу `https://<логин>.github.io/<репозиторий>/`.

## Что внутри
| Раздел | Что делает |
|---|---|
| Узнай понятие / Выбери определение | Тест с четырьмя вариантами; неверные варианты берутся из того же «гнезда» близких понятий |
| Впиши понятие | Ввод термина с клавиатуры (прощает опечатку, есть подсказка за полбалла) |
| Схемы и таблицы | Заполнение схем, таблиц и последовательностей из учебника карточками |
| Соотнеси / Верны ли суждения? / Кто это? | Олимпиадные форматы заданий |
| Олимпиада | Варианты первого этапа республиканской олимпиады с пояснениями |
| Поиск по учебнику | Ответ на вопрос: определение, схема и фрагменты пособия с параграфом и страницей |
| Словарь, Мой прогресс | Повторение и личная статистика (хранится в браузере ученика) |

## Как дополнять
- `data/terms.js` — понятия: `t(класс, параграф, 'группа', 'термин', 'определение', ['синонимы'], доп)`.
  **Группа** — набор близких понятий; из неё подбираются неверные варианты, поэтому новые понятия
  добавляйте в подходящую группу (минимум 3–4 понятия в группе).
- `data/schemes.js` — схемы (`classify` — разложить по колонкам, `table` — таблица, `order` — последовательность).
- `data/olymp.js` — олимпиадные варианты (`mcq`, `input`, `match`) и персоналии.
- `data/corpus.js` — текст учебников для поиска; пересобирается командой `python3 tools/build_corpus.py` (нужен `pip install pymupdf`).
