# «Не пустослов» — бит

Минус в духе раннего Гуфа: медленный boom-bap, грустное пиано, пыльные барабаны, винил.
Всё синтезировано кодом (`make_beat.py`), без чужих сэмплов, так что бит можно использовать свободно.

- **Темп:** 86 BPM (свинг 56 % на шестнадцатых)
- **Тональность:** ля минор, круг Am9 – Fmaj7 – Dm9 – E7(b9), по 1 аккорду на такт
- **Длительность:** 5:50, 124 такта (1 строка текста ≈ 1 такт)
- **Уровень:** ≈ −13 LUFS, пик −2 dBFS (оставлен запас под вокал)

| Время | Часть | Тактов | Что звучит |
|---|---|---|---|
| 0:00 | Интро | 4 | пиано «из соседней комнаты» (фильтр), rhodes-мотив, треск винила |
| 0:11 | Куплет 1 | 16 | барабаны + бас + пиано |
| 0:56 | Припев | 8 | + мелодия rhodes + струнный пэд |
| 1:18 | Куплет 2 | 16 | |
| 2:03 | Куплет 3 | 16 | |
| 2:47 | Припев | 8 | |
| 3:10 | Куплет 4 | 24 | самый длинный куплет — 23 строки |
| 4:17 | Бридж | 8 | половинный размер: малый на «3», рим, пэд — для медленной читки |
| 4:39 | Припев ×2 | 16 | |
| 5:24 | Аутро | 8 | без барабанов, пиано уходит под фильтр и затихает — под «Голуби в парке…» |

Перед каждой новой частью барабаны обрываются на последней доле (брейк + лёгкий «засос»),
чтобы вход в припев и новый куплет был слышен.

Пересобрать (нужны `numpy`, `scipy`, `ffmpeg`):

```bash
python3 make_beat.py
```

Темп, тональность, длину частей и свинг можно поменять в начале скрипта (`BPM`, `CHORDS`, `SECTIONS`, `SWING`).
