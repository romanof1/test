# Выход

- `who_crossed_the_ocean.mp4` — фрагмент «Кто плыл через океан»: 58 с, 1920×1080, 60 fps, H.264/yuv420p, AAC. Озвучки нет, в дорожке только музыка и SFX.
- Пересборка: `bash src/build.sh`. Сначала синтезируется аудио, затем рендерятся кадры по i/60, собирается MP4 и запускается проверка.
- Превью в браузере: открыть `src/index.html` (`?t=12.3` — с нужной секунды). Это не замена MP4.
